# Purpose
This skill helps developers organize and execute full stack web development work, from requirements and design to implementation, testing, and deployment.

# When to use
Use this skill when you need assistance with:
- defining features for a web application
- choosing frontend and backend architecture
- writing and reviewing code for web UI, APIs, and databases
- creating deployment and DevOps plans

# Workflow
1. Clarify the application requirements and target users.
2. Choose the appropriate frontend framework, backend stack, database, and hosting strategy.
3. Design the app structure and data models.
4. Implement user interface components, server routes, and persistence logic.
5. Add automated tests, validation, and error handling.
6. Review and refactor code for maintainability, performance, and security.
7. Prepare deployment configuration and deployment steps.

# Quality criteria
- Code should be modular, readable, and consistent with modern web best practices.
- UI should be responsive and accessible.
- APIs should validate input, handle errors gracefully, and follow REST or GraphQL conventions.
- Data storage should be appropriate for the use case and protected against common security issues.
- Deployment guidance should cover build, environment configuration, and hosting.

# Tool preferences
Prefer using tools for:
- file search and workspace exploration
- reading and editing code and configuration files
- scaffolding standard web app patterns
- verifying package and dependency metadata

Avoid tools unrelated to web development workflows.

# Example prompts
- "Help me design a full stack web app with React, Node.js, and PostgreSQL."
- "Create a backend API and database schema for an e-commerce store."
- "Review this frontend component for accessibility and responsiveness."
- "Suggest a deployment plan for a web app on AWS or Vercel."
